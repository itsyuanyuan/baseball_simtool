Does the baseball add up?

Repeatable checks of the current engine. These results describe the model, not a prediction of real player performance.

01 / All-average league vs. MLB

MLB reference: 2025 league-average batting. Rates use the rounded source totals. Model OBP includes HBP and sacrifice flies. The baseline uses validation seeds that were not used to tune coefficients. All 11 ratings are 50, including error tendency; neutral park, normal fatigue and bullpen rules.

02 / Power and patience vs. bat control

Illustrative ratings: Schwarber-like = contact 35 / power 95 / eye 90. Ichiro-like = contact 95 / power 20 / eye 55. Average = 50 / 50 / 50. Elite pitching = 90 stamina, velocity, movement, control and sequencing; average pitching = 50.

The model does not represent Ichiro’s speed or infield-hit skill, or either hitter’s handedness. These are archetypes, not historical player replicas. Approximate sampling uncertainty for a 20% event rate at 5,000 PA is ±1.1 percentage points (95%); this does not measure model accuracy.

Reproduce the experiment

Run python checks.py from the project directory, then refresh this page. The report records the engine hash, raw baseline counts, ratings and sample sizes. Download result JSON.
